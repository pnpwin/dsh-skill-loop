# Проверка автоматического обучения и написания skill — v0.2.0

Проверен установленный рабочий плагин, а не подменённый proposer. Две контрольные задачи выполнялись в отдельной канонической cwd в режиме review. Рабочий turn-end listener самостоятельно вызывал Reflector/Curator. Gold insight, готовый skill, ручные confirm/approve и auto не использовались.

## Исправление методики

Цепочки команд с `&&` намеренно не считаются распознанной проверкой: последняя успешная команда может скрыть ошибку теста. В этом прогоне каждое наблюдение fail/pass получено отдельной простой командой `node --test --test-reporter=spec ...`; подтверждение второго эпизода включает настоящий `job/settled` и `tool/result` с успешным завершением.

## Два эпизода

1. **Числовая сортировка без мутации входа:** три теста упали, функция исправлена, те же три теста прошли. Reflector сохранил один урок; insights отсутствовали, Curator корректно не запускался. Результат `lessons-only`.
2. **Условное восстановление бюджетных полей:** три теста упали при восстановлении всего старого snapshot. Исправление сохраняет текущие настройки, ограничивает восстановление двумя полями и не затирает отличающиеся последующие изменения. Те же три теста прошли. Реальный Reflector выдал основание для Curator; Curator создал новый pending-кандидат. Результат `pending-review`.

**Не подтверждено этой проверкой:** независимая оценка кандидата, применение опубликованного skill следующей задачей, причинное улучшение качества, безопасность конкурентной записи или end-to-end экономия токенов.
